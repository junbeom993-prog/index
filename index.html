🔗 TeamPlan 시작하기

Firebase를 연결하면 팀원 모두가 같은 데이터를 실시간으로 공유할 수 있습니다.
Firebase 없이 개인 로컬 모드로도 바로 시작 가능합니다.

1
Firebase 프로젝트 생성
console.firebase.google.com 접속 → 새 프로젝트 만들기 (Google Analytics 불필요)
2
Realtime Database 활성화
왼쪽 메뉴 → Realtime Database → 데이터베이스 만들기 → 테스트 모드로 시작 → URL 복사
예: https://my-team-abc123-default-rtdb.firebaseio.com
3
아래에 URL 붙여넣기 후 연결
연결 후 이 HTML 파일을 팀원들과 공유하면 끝!
